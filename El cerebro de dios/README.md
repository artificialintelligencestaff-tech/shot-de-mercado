# Proyecto Shot de Mercado

**Bot autónomo de predicción de aceleraciones verticales en activos blockchain, con salida vía Telegram.**

## ¿Qué es?

Un sistema que detecta, antes de que ocurran, movimientos >20% en activos cripto (24-48h), usando multiplicidad de filtros independientes. Emite alertas accionables para usuarios no-técnicos vía bot de Telegram.

## Estado actual

- **Fase:** 0 (migración a serverless)
- **Operativo:** captura T+0, quality gate, scoring v7, alertas Telegram
- **En construcción:** workflows GitHub Actions, catálogo de fuentes, consolidación de pipelines
- **Falta:** watchlist automática, feedback loop, autonomía 24/7
