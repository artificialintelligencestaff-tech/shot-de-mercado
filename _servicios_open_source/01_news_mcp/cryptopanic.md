# CryptoPanic

**Repo:** https://github.com/CryptoPanic/cryptopanic
**Licencia:** MIT
**Gratis:** sí (plan free 20 req/min, 10k req/día)
**Requisitos:** Python/Node/Go/Rust, API key (gratis)
**Qué hace:** Agregador de noticias crypto con RSS/Reddit/Twitter/Webhooks. Filtros por moneda, fuente, región. Webhooks para alertas en tiempo real.
**Por qué sirve al proyecto:** Fuente consolidada de noticias para el colector de narrativas (script_115). API simple, sin key obligatoria para uso básico, rate limits generosos.
**Recomendación:** integrar como fuente primaria de noticias en pipeline narrativo
